Source archive excludes private game/ROM fixtures. CAREN_CRT may point to your own Caren CRT for run_easyflash.py; --quick uses an original synthetic fixture. GHDL conversion tools and Icarus/Quartus must be installed separately. Source includes the disabled 1581 code for future work. C64 ROMs are not included.
Game rebuild: run tobypink-pocket/source/build.ps1 with -Toolchain pointing to cc65. Set C1541 to the VICE c1541 executable, then run tobypink-pocket/make_disk.py. The resources folder includes the original reward PRGs and V027 bank. Run tests/run_pcm.py before the PCM memory/game tests to create their bank fixture.
