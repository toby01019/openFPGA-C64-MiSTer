## C64 Pocket 0.5.3-alpha — Hardware-tested autostart fix

Fixes disk autostart doing nothing after a cold start: the internal keyboard
boot guard was incorrectly treated as manual input, cancelling autostart.

**Hardware testing confirmed D64/G64 automatic loading and game start,
manual LOAD*, and in-game disk swaps without unwanted LOAD/RUN.**
The released FPGA bitstream is byte-identical to the tested 0.5.3-test.
This remains an alpha, not a guarantee for every game or replacement ROM.

### Installation
Download **C64-Pocket-0.5.3-Test-SD-EN.zip**. Back up the SD, power off Pocket,
extract to its root, merge folders and replace core files. From 0.5.2 there
is **no renaming or folder migration**. From 0.5.1 or older, follow the
included migration instructions. Provide your own system ROMs.

Under **Core Settings > Disk assist**, use **Auto start + activity**.
At empty BASIC READY select D64/G64 in Disk 8, close the menu and release
buttons. Manual LOAD*/RUN remain available; Activity only disables autostart.

### Validation and availability
FPGA build, timing and focused regression tests passed; see VALIDATION.txt.
Only autostart cancellation wiring changed functionally. Picture, audio,
disk and keyboard RTL remain unchanged. Hardware tests cover the checks above.
The registered core ID remains `toby01019.C64` on platform `c64`.
